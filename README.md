# MirthLens

A simple MirthLens optimizer for event driven architecture.

With MirthLens, you get a lightweight tool that stays out of your way.

**What you get**

- A simple MirthLens optimizer for event driven architecture

## Key Features

- A simple MirthLens optimizer for event driven architecture

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthLens.git`
2. `cd MirthLens`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure MirthLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
